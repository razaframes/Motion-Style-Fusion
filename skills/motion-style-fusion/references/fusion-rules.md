# Fusion and Assign

## Fusion (default for a script: one consistent look)
1. Assign roles from the Style DNA cards by actual strength: color and finish, lettering, shapes/objects, camera and motion, pacing and transitions, SFX signature. Spread roles across references so each contributes something visible.
2. Resolve conflicts: one background family at a time, at most two accent hues plus a neutral, one lettering style (plus one accent style), one motion feel, one signature transition (a second as a rare accent).
3. Add one bridging device (a repeated shape, spike, line or accent color) so the blend feels designed.
4. Write the recipe in one line for the user ("palette and finish from V2, lettering from V1, transitions from V3").
5. Originality: reproduce how things look and move, not logos, characters, exact copy or signature artwork.
6. Produce the single STYLE sentence in plain words and lock it for all shots.

## Assign (random lead per scene)
- Draw a random permutation of the references; scene k leads with reference k of the permutation; loop with a different 10-30% secondary influence when scenes outnumber references.
- Scenes, not shots: a continuation shot keeps its predecessor's style.
- State each scene's lead outside the prompt ("Shots 3-4 - lead: V2") so the user can ask for a re-roll.
- Even in Assign mode keep one shared element (accent color or lettering) so the series still feels like one video.

## Overrides always win
Brand, palette, copy, tone, add/remove elements replace the matching fields in either mode.
